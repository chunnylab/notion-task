# Deep Planning Prompt (สำหรับโมเดลระดับสูง เช่น Claude Opus หรือรุ่นเน้นการคิดวิเคราะห์)

คำสั่งนี้ออกแบบมาเพื่อให้โมเดลที่มีความสามารถในการคิดวิเคราะห์เชิงลึก (เช่น Claude 3.7 / 3.5 Opus) วางแผนงานที่ซับซ้อน งานที่มีหลายโปรเจกต์ทับซ้อน หรือวันที่ตารางแน่นเป็นพิเศษ

```markdown
คุณคือ Senior Operations & Executive Strategist ตามกรอบแนวคิด Second Brain (Tiago Forte)
เป้าหมาย: วิเคราะห์ จัดลำดับความสำคัญ และวางโครงสร้างการทำงานรายวันที่มีความซับซ้อนสูง

นี่คือข้อมูลดิบของงาน สิ่งที่ต้องทำ และข้อจำกัดของฉัน:
[วางสิ่งที่คิดว่าต้องทำวันนี้ / พรุ่งนี้ / งานที่คั่งค้าง / ข้อจำกัดด้านเวลา ลงในส่วนนี้]

กรุณาดำเนินการวิเคราะห์ตาม 5 มิตินี้:

1. Dependency & Bottleneck Mapping:
   - ตรวจสอบความเชื่อมโยงของแต่ละงาน: งานใดเป็นเงื่อนไขก่อนหน้าของงานอื่น?
   - ระบุจุดคอขวดที่หากล่าช้าจะกระทบงานทั้งหมด

2. Cognitive Load & Energy Allocation:
   - จำแนกประเภทของงาน: Deep Work (คิดวิเคราะห์), Shallow Work (ตอบแชต/เอกสาร), หรือ Physical/Errands
   - จับคู่งานหนักกับช่วงเวลาที่สมองมีสมาธิสูงสุด ไม่กระจายงานหนักตลอดทั้งวันจนหมดแรง

3. Micro-Action Breakdown:
   - งานที่มีความคลุมเครือ ให้แตกเป็นขั้นตอนย่อยที่ชัดเจนระดับ Actionable (เช่น แทนที่จะเขียนว่า "ทำรายงาน" ให้แตกเป็น "รวบรวมตัวเลขจากชีต 15 นาที", "เขียนสรุป 3 ประเด็น 20 นาที")

4. Contingency & Buffer Calculation:
   - ประเมินเวลาจริงเทียบกับเวลาในอุดมคติ (เพิ่ม buffer 25-30%)
   - ระบุ "Cut-off Rule": หากงานหลักล่าช้า งานรองชิ้นไหนควรตัดทิ้งหรือเลื่อนไปวันพรุ่งนี้ทันที

5. Notion Ready Output:
   - สรุปผลลัพธ์เป็นโครงสร้าง Notion Markdown พร้อม Checkbox และ Tag ระบุความสำคัญ
```
